# Minuit 2.0 기획서 (v3 — 포스터 화보)

> 유지: **신데렐라 모티프 + 종이 콜라주.**
> 목표: 실제로 공부가 더 되는 집중 도구 + **한 장 한 장이 포스터 화보처럼 보이는 화면.**
> 그림: **캐릭터만 새로 그린다(4장).** 나머지는 기존 에셋 재활용 + 코드로 그리는 그래픽.
> 상태: 승인 전. 승인 전까지 코드·그림 생성 0.
>
> 참고: ① 틀 밖으로 손을 내민 입체 구도 일러스트 ② 흑백 콜라주 + 코발트 블루 그래픽 포스터
> ③ 조각이 하나씩 툭툭 붙으며 완성되는 콜라주 영상. **구도를 베끼지 않고 원리만 가져온다.**

## 0. 지금 버전의 근본 문제 (v2와 같음)

| # | 문제 | 영향 |
|---|---|---|
| 1 | 집중하는 **도중에** 화면이 제일 화려하다 | 보상이 집중을 방해 |
| 2 | 무엇을 할지 안 정하고 시작한다 | 앉아서 고민하다 시간이 감 |
| 3 | 끝나고 돌아보는 단계·휴식이 없다 | 뭘 했는지 안 남고, 쉬다가 폰으로 샘 |
| 4 | 오브젝트 20여 개가 처음부터 다 붙어 난잡하다 | 완성도가 낮아 보임 |
| 5 | 그림체가 섞여 있다 | "AI 콜라주" 느낌 |

## 1. 한 줄 컨셉

**"하룻밤 = 집중 4번 = 화보 4장. 한 번 끝낼 때마다 새 화보가 한 장씩 인쇄되고, 네 번째가 자정의 표지."**

- 매 세션 화면이 잡지 화보 한 장이다. 단계마다 **Vol. I ~ IV** 로 레이아웃과 캐릭터 포즈가 바뀐다.
- 집중하는 동안에는 화보가 **멈춰 있다.** 움직이는 건 파란 모래와 시간 숫자뿐.
- 집중이 끝나면 쉬는 시간에 **다음 화보가 조각조각 툭툭 붙으며 완성되는 연출**(참고 ③)이 보상이다.
- 하룻밤 4장이 다 모이면 **"오늘 밤의 화보집"** 으로 아카이브에 저장된다.

## 2. 아트 디렉션

### 2-1. 색

| 역할 | 색 | 이유 |
|---|---|---|
| 포인트(유일한 색) | **코발트 블루 `#1B1FD1` 근처** | 자정의 밤하늘, 유리구두의 푸른 빛. 참고 ②③ 모두 이 계열이라 흑백 콜라주와 가장 강하게 대비된다. 지금 캐릭터의 붉은 아이라인보다 신데렐라 상징(드레스·유리구두)과 더 직접 이어진다 |
| 바탕 | 종이 흰색 `#ECEBE7`, 잉크 검정 `#121216` | 밝은 띠 / 어두운 띠 |
| 사진 재료 | 완전 흑백 | 캐릭터 포함 |
| 보조 | 파랑 30% 투명 (그러데이션·망점) | 면을 채울 때만 |

**규칙: 색은 파랑 하나.** 캐릭터 피부의 분홍도 뺀다. 대신 파랑이 들어가는 곳을 아주 정해 둔다(아래).

### 2-2. 화면 재료 4종

| 재료 | 예 | 출처 | 크레딧 |
|---|---|---|---|
| **흑백 사진 조각** | 캐릭터, 회중시계, 유리구두, 크리스털, 시계탑, 고딕 배경 | 캐릭터만 새로, 나머지 기존 에셋을 흑백·고대비로 | 캐릭터만 |
| **파란 평면 도형** | 큰 4각 별(요정의 마법), 비둘기 실루엣(신데렐라를 돕는 새), 유리구두·호박마차·티아라 실루엣, 굵은 세로 띠, 체크무늬 띠 | 코드(SVG 경로) | 0 |
| **가는 선** | 궤도 타원, 점선 원, 원을 따라 도는 글씨, 백합·장식 선화 | 코드 | 0 |
| **인쇄 질감** | 망점(하프톤), 격자 점, 종이 결, 타자기 글씨 블록, 바코드 같은 검은 막대 | 코드 | 0 |

- 모든 사진 조각에 **흰 오린 테두리 + 그림자**(스티커처럼 오려 붙인 느낌).
- 캐릭터의 어두운 부분엔 **망점**을 입혀 인쇄물처럼. 일부 조각은 파랑으로 살짝 어긋나게 찍힌 듯(리소 인쇄 느낌).
- **글씨가 곧 장식:** 타자기 글꼴 블록에 실제 정보를 쓴다. 예)
  `SESSION 02 / 25:00 / MATH — CH.3 Q.1–20 / ENDS 21:35`
  뜻 없는 가짜 글자는 쓰지 않는다.

### 2-3. 글꼴

| 용도 | 글꼴 |
|---|---|
| 큰 시간 숫자·제목 | Cormorant Garamond (가는 세리프) |
| `Minuit` 로고 | Pinyon Script (필기체) |
| 정보 블록 | IBM Plex Mono (타자기 느낌) |
| 한글 | Noto Serif KR |

오프라인에서도 보이게 필요한 글자만 잘라 파일로 넣는다.

### 2-4. 캐릭터 (새로 그릴 4장)

- **흑백 화보 사진처럼.** 생성은 컬러로 하고(모델이 더 잘 그림), 앱에서 코드로 흑백 + 망점 처리 → 나중에 톤을 바꿔도 다시 안 뽑아도 된다.
- 얼굴·머리 원본 유지(은발, 일자 앞머리, 처진 눈, 아이라인, 초커). 흑백이라 붉은 아이라인은 짙은 회색 선으로 보인다.
- **모래시계는 손에서 뗀다** → 포즈가 자유롭다. 옷마다 모래시계 좌표를 잴 필요(`geom.json`)도 없어진다.
- **4장 모두 다른 포즈** = 화보 4컷. 얼굴은 같은 레퍼런스로 고정.

| Vol. | 옷 | 포즈·구도 (입체감 원리: 원근, 틀 깨기, 기울기) |
|---|---|---|
| I Prélude 서곡 | 재 묻은 앞치마·낡은 옷 | 옆으로 앉아 무릎을 안고 고개만 돌려 화면을 봄. 머리카락이 틀 밖으로 흘러내림 |
| II Nocturne 야상곡 | 마법이 반쯤 걸린 옷 | 위를 올려다보며 한 손을 하늘로 뻗음(요정의 별을 잡으려는). 손끝이 틀 위로 튀어나감 |
| III Valse 왈츠 | 무도회 드레스 | 춤추다 돌아보는 순간. 치마가 크게 퍼지며 화면 아래 틀을 넘음, 기울어진 구도 |
| IV Minuit 자정 | 드레스 + 유리구두 | **화면을 향해 손을 크게 내밂**(가장 강한 원근). 턱을 괸 다른 손, 비스듬한 시선. 손이 틀을 뚫고 나옴 |

## 3. 화면 구성 — 포스터 레이아웃

### 3-1. 세로 (기본)

```
┌──────────────────────┐
│█ Minuit        SESSION 02 │ ← 왼쪽 굵은 파란 세로 띠
│█ 23:14 (파랑, 거대)       │   밝은 띠: 시간·단계·끝나는 시각
│█   ★        ~궤도선~      │
│█▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│ ← 파란 체크무늬
│█ ┌─────────────────┐   │   어두운 틀: 흑백 배경 + 캐릭터
│█ │   캐릭터 ──손──→ 틀 밖│   캐릭터 일부(손·머리·치마)는 틀을 넘음
│█ │       ⧗ 파란 모래시계 │   모래시계: 원 글씨에 둘러싸인 파란 평면 그래픽
│█ └─────────────────┘   │
│█▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓│
│█ 이번 목표 / 타자기 정보 블록│ ← 밝은 띠: 목표, 동화 한 줄, ◆◆◇◇
└──────────────────────┘
```

- Vol.마다 띠의 위치·두께, 틀 모양(사각/아치/원), 별·새의 배치가 바뀐다 → 4장이 서로 다른 화보처럼 보인다. 배치는 코드의 표 하나(`POSTER[vol]`)로 관리.
- 시간 숫자는 **항상 다 읽혀야** 한다(캐릭터가 가리지 않는 자리 고정).

### 3-2. 가로 = 잡지 펼침면

왼쪽 페이지: 캐릭터(같은 그림 재사용) / 가운데 접힌 선 / 오른쪽 페이지: 거대한 시간 + 정보 블록. 책상에 눕혀 세워 둬도 멀리서 시간이 보인다.

### 3-3. 상태별

| 상태 | 화면 |
|---|---|
| 준비 | 지금 Vol. 화보 위에 초대장 종이(오늘 할 일 3개), 시간 칩, "자정까지" 티켓이 붙어 있음 |
| 집중 | 종이들이 떨어져 나가고 화보만. **정지 화면**: 파란 모래와 시간 숫자만 움직임 |
| 뒤집힘 | 검은 화면 |
| 회고 | 타자기 글씨 메모지 한 장(목표 / 결과 3택 / 별점 / 딴짓 횟수) |
| 휴식 | **다음 Vol. 화보가 조각조각 붙으며 완성**(보상) → 휴식 타이머 + 휴식 제안 + 생각 메모 |
| 자정 | Vol. IV 표지 완성 + 시계탑 종 + 파란 별 반짝임 → "오늘 밤의 화보집" 저장 |
| 아카이브 | 날짜별 화보집. 4장 중 모은 만큼 넘겨 봄. 통계는 정보 블록 스타일로 |

## 4. 움직임 (참고 ③의 원리)

| 원칙 | 구현 |
|---|---|
| **스톱모션처럼 "툭툭"** | 부드럽게 미끄러지지 않고, 조각이 0.1초 단위로 뚝 나타나며 살짝 크게 → 제자리. 약간 비뚤어진 각도로 붙음 |
| **하나씩 순서대로** | 배경 → 띠·도형 → 사진 조각 → 캐릭터 → 글씨 순. 조각 하나 0.12~0.2초, 전체 약 2~3초 |
| **바꿔 끼우기** | 원형 조각 속 그림이 달 → 별 → 시계로 휙휙 바뀌다가 멈추는 식의 교체 연출 (휴식 화면에서만) |
| **집중 중엔 정지** | 위 연출은 준비·휴식·자정에서만. 집중 중엔 모래·숫자 외 움직임 0 |
| **종이 효과 재사용** | 종이가 떨어져 나갈 때는 지금의 구김 효과(`drawPaper`)를 그대로 씀 |

## 5. 공부 흐름 (v2와 같음)

```
[오늘의 초대장] 할 일 1~3개 (하루 한 번)
  → [준비] 할 일 고르고 "이번엔 어디까지" 한 줄 → 시간
  → [집중] 정지 화보 + 파란 모래. 폰을 뒤집으면 화면 꺼진 채 진행. 딴생각은 메모로
  → [회고 15초] 다 했다/일부/못 했다 + 집중도 ★1~5
  → [휴식 5분] 다음 화보 완성 연출 + 휴식 제안 + 메모 다시 보기
  → 4번째면 [자정] 긴 휴식 15~30분
```

| 규칙 | 내용 |
|---|---|
| 집중 길이 | 25분 기본, 15 / 25 / 45 / 50 |
| 휴식 | 5분(45·50분이면 10분), 4번째 뒤 15~30분. 건너뛰기 가능 |
| 그만두기 | 2초 길게 누르기. 그 Vol.은 못 얻음(이미 얻은 건 유지) |
| 새 밤 | 새벽 4시 기준으로 하루가 바뀜 |
| 폰 뒤집기 | 뒤집으면 검은 화면으로 진행, 들어 올리면 딴짓 1회 기록. 설정에서 끔 가능 |
| 화면 잠금 | 타이머는 계속. 돌아오면 맞게 줄어 있음. 끝나는 시각을 항상 표시(서버 없어 알림 불가) |

## 7. 기술 방향

| 항목 | 내용 |
|---|---|
| 파일 | `index.html`(코드) + `img/*.webp` + 글꼴 조각. 코드만 바꾸면 그림은 다시 안 받음 |
| 그래픽 | 파란 도형·선·글씨는 SVG 도형(필터 없이 — iOS에서 SVG 필터가 깨짐) |
| 흑백·망점 | 그림을 처음 불러올 때 캔버스에서 한 번만 처리해 저장. 매 프레임 필터 금지 |
| 레이아웃 | `POSTER[vol]` 표 하나에 Vol.별 띠·틀·조각·도형 배치 |
| 로직 분리 | 타이머·사이클·기록 계산을 화면과 분리해 브라우저 없이 테스트 |
| 재사용 코드 | 종이 구김(`drawPaper`), 시계탑 바늘, 초침 소리, 홈 화면 높이 보정(`appH`) |
| 저장 | `midnight.v2` 하나로. 옛 `midnight.rec` 기록은 처음 열 때 옮김 |

## 8. 성능 상한 (아이폰)

| 항목 | 상한 |
|---|---|
| 화보 완성 연출 | 60fps, 최악(조각 20개 + 별·새 + 종이 구김 동시)에서도 50 이상 |
| 집중 화면 | 모래만 움직임, 그리기 30fps 이하 |
| 뒤집힘 | 그리기 0 |
| 첫 화면 | 4G에서 2초 안 (첫 Vol. 그림만 먼저, ≤ 800KB) |
| 그림 전체 | ≤ 3MB (지금 4.8MB) |
| 한 화면 사진 조각 | ≤ 8개 (난잡함 방지 겸) |

- [ ] 할 일을 고르고 시작하면 25:00부터 1초씩 줄고 끝나는 시각이 표시된다
- [ ] 끝나면 회고 메모지가 뜨고 버튼 2번으로 닫힌다
- [ ] 회고 후 5분 휴식이 돌고 건너뛸 수 있다. 4번째 뒤에는 긴 휴식이 제안된다
- [ ] 집중 중 메모를 적으면 바로 집중 화면으로 돌아오고, 휴식 화면에 그 메모가 보인다
- [ ] 그만은 2초 길게 눌러야 동작한다

**딴짓 막기**
- [ ] 집중 중 폰을 뒤집으면 1초 안에 화면이 검게 되고, 들면 다시 켜지며 딴짓이 1 늘어난다
- [ ] 화면을 잠갔다 3분 뒤 켜면 남은 시간이 3분 줄어 있다

**화보**
- [ ] Vol. I~IV가 서로 다른 레이아웃·포즈로 보인다
- [ ] 집중 중에는 모래와 시간 숫자 외에 움직이는 것이 없다
- [ ] 집중을 끝내면 휴식 시작 때 다음 Vol.이 조각조각(스톱모션) 붙으며 완성된다
- [ ] 4번째를 끝내면 자정 표지 + 종 + 별 연출이 나오고 아카이브에 그날 화보집이 생긴다
- [ ] 색은 파랑 하나뿐이고, 모든 사진 조각에 오린 테두리·그림자가 있다
- [ ] 시간 숫자가 어느 Vol.에서도 가려지지 않는다
- [ ] 새벽 4시 이후 처음 열면 새 밤(Vol. I)으로 시작한다

**기록**
- [ ] 아카이브에서 날짜별 화보집과 오늘·이번 주 통계(집중 시간, 할 일 달성률, 평균 집중도, 딴짓)가 맞게 나온다
- [ ] 옛 기록(`midnight.rec`)이 옮겨져 있다

**아이폰·품질**
- [ ] 홈 화면 앱 세로·가로에서 아래 빈칸이 없다
- [ ] 입력할 때 키보드가 입력칸을 가리지 않는다
- [ ] 비행기 모드에서도 열리고 글꼴이 깨지지 않는다
- [ ] 코드만 바꿔 배포하면 그림을 다시 받지 않는다
- [ ] 콘솔 오류 0건, 성능 상한 충족
