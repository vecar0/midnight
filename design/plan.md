# Minuit 2.0 기획서 (v4 — 흑백 세계, 색을 가진 신데렐라)

> 유지: **신데렐라 모티프 + 종이 콜라주.**
> 목표: 실제로 공부가 더 되는 집중 도구 + **한 장 한 장이 포스터 화보처럼 보이는 화면.**
> 그림: **캐릭터만 새로 그린다(Vol.당 1장, 총 4장).** 나머지는 기존 에셋 재활용 + 코드 그래픽.
> 상태: 승인 전. 승인 전까지 코드·그림 생성 0.
>
> 참고: ① 틀 밖으로 손을 내민 입체 구도 일러스트(캐릭터만 컬러, 주변은 은빛 흑백)
> ② 흑백 콜라주 포스터 ③ 조각이 하나씩 툭툭 붙으며 완성되는 콜라주 영상. **구도를 베끼지 않고 원리만 가져온다.**

## 0. 지금 버전의 근본 문제

| # | 문제 | 영향 |
|---|---|---|
| 1 | 집중하는 **도중에** 화면이 제일 화려하다 | 보상이 집중을 방해 |
| 2 | 무엇을 할지 안 정하고 시작한다 | 앉아서 고민하다 시간이 감 |
| 3 | 끝나고 돌아보는 단계·휴식이 없다 | 뭘 했는지 안 남고, 쉬다가 폰으로 샘 |
| 4 | 오브젝트가 의미 없이 흩어져 있다 | 완성도가 낮아 보임 |
| 5 | 그림체가 섞여 있다 | "AI 콜라주" 느낌 |

## 1. 한 줄 컨셉

**"흑백의 세계에서 마법에 걸린 신데렐라만 색을 가진다. 하룻밤 = 집중 4번 = 화보 4장."**

- 매 세션 화면이 잡지 화보 한 장. 단계마다 **Vol. I ~ IV** 로 포즈·옷이 바뀐다.
- **집중할수록 그녀에게 색이 돌아온다**(Vol. I 거의 흑백 → Vol. IV 완전한 컬러). 같은 그림의 채도를 코드로 조절 — 크레딧 0.
- 집중하는 동안 화보는 **멈춰 있다.** 움직이는 건 은빛 모래와 시간 숫자뿐.
- 집중이 끝나면 쉬는 시간에 **다음 화보가 조각조각 툭툭 붙으며 완성**(참고 ③) = 보상.
- 4장이 모이면 **"오늘 밤의 화보집"** 으로 아카이브에 저장.

## 2. 아트 디렉션

### 2-1. 색 — 색은 캐릭터에게만

| 역할 | 색 |
|---|---|
| **캐릭터** | 유일한 컬러. 흰 피부의 혈색, 분홍 볼·입술, 붉은 눈가, 옷의 은은한 색 |
| 장식·사진 조각·배경 | 완전 흑백 + 은빛(크롬 그러데이션) |
| 바탕 | 종이 흰색 `#F2F1EE`, 잉크 검정 `#111113` |
| 시간 숫자·모래시계 | 크롬 은색, 모래는 흰색 |

| Vol. | 캐릭터 채도 |
|---|---|
| I 서곡 (재투성이) | 거의 흑백, 볼에만 옅은 혈색 |
| II 야상곡 | 피부·입술에 색 |
| III 왈츠 | 드레스에도 은은한 색 |
| IV 자정 | 완전한 컬러 |

### 2-2. 장식 재료 — 고급스러운 흑백 은빛

| 재료 | 예 | 출처 | 크레딧 |
|---|---|---|---|
| 은빛 오브젝트 | 샹들리에 크리스털, 티아라, 회중시계, 열쇠, 톱니, 깃털, 유리구두, 유리 파편 | 기존 에셋(`crystals`, `d3*`, `watch*`, `shard*`)을 흑백·고대비로 | 0 |
| 판화·레이스 | 옅은 시계탑 판화, 레이스·악보 띠 | 기존 `tower2`, `stripV/H` | 0 |
| 틀과 장식선 | 이중 테두리 틀, 틀 양옆 은빛 장식 화살표, 크롬 글씨 | 코드(SVG·CSS) | 0 |
| 은빛 모래시계 | 원을 따라 도는 글씨에 둘러싸인 유리 모래시계, 흰 모래 = 남은 시간 | 코드 | 0 |
| (선택) 바로크 장식 세트 | 크롬 모서리 장식, 백합 문양, 리본, 진주 줄 | 한 장에 모아 1회 생성 후 잘라 씀 | 2~4 |

- 사진 조각에는 그림자를 줘서 종이에 붙인 듯. 틀 안 배경은 기존 `bgP/bgL` 을 아주 어둡게.
- **글씨가 곧 장식:** 타자기 글꼴 블록에 실제 정보(`SESSION 04 / 04 · ENDS 21:35`). 가짜 글자 금지.
- 한 화면 사진 조각 6~10개. 요소는 많되, 틀·글씨 줄을 맞춰 정돈한다.

### 2-3. 글꼴

| 용도 | 글꼴 |
|---|---|
| 큰 시간 숫자 | Cormorant Garamond (가는 세리프, 크롬 그러데이션) |
| `Minuit`·Vol. 이름 | Pinyon Script (필기체) |
| 정보 블록 | IBM Plex Mono |
| 한글 | Noto Serif KR |

오프라인에서도 보이게 필요한 글자만 잘라 넣는다.

### 2-4. 캐릭터 — 한 장으로 세로·가로 둘 다

- **Vol.마다 전신 그림 1장(2k 이상)을 뽑고, 세로는 상반신으로 잘라 쓰고 가로는 전신을 쓴다.** 그래서 총 4장.
- 공통 포즈: **틀 아래 모서리에 걸터앉아, 한 손은 화면 쪽으로 크게 내밀고(원근), 다른 손은 턱이나 머리 쪽. 다리는 꼬아서 늘어뜨림.**

| 화면 | 보이는 부분 | 틀 깨기 |
|---|---|---|
| **세로** | 상반신 클로즈업(다리는 틀 아래에서 잘려 안 보임) | **내민 손이 틀 옆을 뚫고 나옴** |
| **가로** | 전신 | **다리가 틀 아래로 나와 늘어짐**, 손은 틀 안 |

| Vol. | 옷 | 포즈 변주 (공통 포즈 안에서) |
|---|---|---|
| I 서곡 | 재 묻은 낡은 옷, 맨발 | 무릎을 당겨 앉고 고개만 돌려 봄. 손은 소매 끝을 쥠 |
| II 야상곡 | 마법이 반쯤 걸린 옷 | 위를 올려다보며 한 손을 들어 마법의 빛을 받음 |
| III 왈츠 | 무도회 드레스 + 유리구두 | 치마가 틀 모서리를 덮으며 넘침, 한 손을 춤추듯 내밂 |
| IV 자정 | 드레스, **구두 한 짝이 벗겨져 떨어지는 순간** | 화면을 향해 손을 크게 내밂, 다른 손은 턱. 가장 강한 원근 |

- 얼굴·머리 원본 유지(은발, 일자 앞머리, 처진 회색 눈+붉은 아이라인, 초커).
- **모래시계는 손에서 뗀다**(코드 그래픽) → 포즈 자유, `geom.json` 불필요.

## 3. 화면 구성

### 3-1. 세로

```
┌────────────────────┐
│ Minuit      VOL. IV · 자정 │
│ ♛┌──────────────┐  │  큰 틀(화면의 대부분), 이중 테두리
│  │  얼굴·상체     ⧗ │  │  은빛 모래시계는 틀 안 오른쪽 위
│◆─│               │─◆│  양옆 은빛 장식 화살표
│  │        내민 손 ──┼→ │  손이 틀 옆을 뚫고 나옴
│ ⚙└──────────────┘  │  열쇠·톱니·크리스털·레이스는 틀 둘레에
│ 23:14  (크롬 은색)      │
│ TONIGHT'S TASK 수학 3단원 │
│ SESSION 04/04 · ENDS 21:35 │
└────────────────────┘
```

### 3-2. 가로

```
┌─────────────────────────────────────┐
│ Minuit        ┌──────────────┐ ♛          │
│ VOL. IV       │  얼굴·상체(전신) │   23:14     │
│               └──────┬───────┘  SESSION   │
│ TONIGHT'S TASK        다리가 틀 밖으로     ENDS     │
│ 수학 3단원              ↘ 떨어지는 유리구두           │
└─────────────────────────────────────┘
```

### 3-3. 상태별

| 상태 | 화면 |
|---|---|
| 준비 | 지금 Vol. 화보 위에 초대장 종이(오늘 할 일 3개), 시간 칩, "자정까지" 티켓 |
| 집중 | 종이들이 떨어져 나가고 화보만. 정지 화면: 모래와 시간만 움직임 |
| 뒤집힘 | 검은 화면 |
| 회고 | 타자기 글씨 메모지(목표 / 결과 3택 / 별점 / 딴짓 횟수) |
| 휴식 | 다음 Vol. 화보가 조각조각 붙으며 완성 + 캐릭터에 색이 번짐 → 휴식 타이머·제안·메모 |
| 자정 | Vol. IV 완전한 컬러 + 시계탑 종 + 은빛 반짝임 → "오늘 밤의 화보집" 저장 |
| 아카이브 | 날짜별 화보집. 통계는 정보 블록 스타일로 |

## 4. 움직임 (참고 ③의 원리)

| 원칙 | 구현 |
|---|---|
| **스톱모션처럼 "툭툭"** | 부드럽게 미끄러지지 않고, 조각이 0.1초 단위로 뚝 나타나며 살짝 크게 → 제자리. 약간 비뚤어진 각도로 붙음 |
| **하나씩 순서대로** | 배경 → 띠·도형 → 사진 조각 → 캐릭터 → 글씨 순. 조각 하나 0.12~0.2초, 전체 약 2~3초 |
| **바꿔 끼우기** | 원형 조각 속 그림이 달 → 별 → 시계로 휙휙 바뀌다가 멈추는 식의 교체 연출 (휴식 화면에서만) |
| **집중 중엔 정지** | 위 연출은 준비·휴식·자정에서만. 집중 중엔 모래·숫자 외 움직임 0 |
| **종이 효과 재사용** | 종이가 떨어져 나갈 때는 지금의 구김 효과(`drawPaper`)를 그대로 씀 |

## 5. 공부 흐름

```
[오늘의 초대장] 할 일 1~3개 (하루 한 번)
  → [준비] 할 일 고르고 "이번엔 어디까지" 한 줄 → 시간
  → [집중] 정지 화보 + 은빛 모래. 폰을 뒤집으면 화면 꺼진 채 진행. 딴생각은 메모로
  → [회고 15초] 다 했다/일부/못 했다 + 집중도 ★1~5
  → [휴식 5분] 다음 화보 완성 연출 + 휴식 제안 + 메모 다시 보기
  → 4번째면 [자정] 긴 휴식 15~30분
```

| 규칙 | 내용 |
|---|---|
| 집중 길이 | 25분 기본, 15 / 25 / 45 / 50 |
| 휴식 | 5분(45·50분이면 10분), 4번째 뒤 15~30분. 건너뛰기 가능 |
| 그만두기 | 2초 길게 누르기. 그 Vol.은 못 얻음(이미 얻은 건 유지) |
| 새 밤 | 새벽 4시 기준으로 하루가 바뀜 |
| 폰 뒤집기 | 뒤집으면 검은 화면으로 진행, 들어 올리면 딴짓 1회 기록. 설정에서 끔 가능 |
| 화면 잠금 | 타이머는 계속. 돌아오면 맞게 줄어 있음. 끝나는 시각을 항상 표시(서버 없어 알림 불가) |

## 6. 에셋 계획

### 재활용 (크레딧 0)

| 기존 | 새 용도 |
|---|---|
| `bgP`, `bgL` | 틀 안 어두운 흑백 배경 |
| `crystals`, `d3*`, `watch1/2`, `shard*`, `oWand`, `oEnvelope` | 은빛 흑백 장식 조각 |
| `tower2`, `hHour/hMin/hSec` | 옅은 판화 배경, 자정 표지의 시계탑 |
| `stripV`, `stripH` | 레이스·악보 띠 |
| `paperIvory`, `paperBlack` | 초대장·회고 메모지 |
| `fx*` | 자정 반짝임 |
| 소리(`tick.mp3`, 종, 부스럭) | 그대로 |
| 안 씀 → 삭제 | `l1~l4`, `p1~p4`(새 캐릭터로 교체), `curtainL/P`, `g*` |

### 새로 (캐릭터 4장)

| 순서 | 내용 | 예상 크레딧 |
|---|---|---|
| 1 | 포즈·그림체 시안 (Flare 저품질, 장당 0.25) 4~6장 | ~1.5 |
| 2 | Vol. IV 확정본 (Nano Banana Pro 2k, 얼굴 레퍼런스 = 지금 `p1` + 그림체 레퍼런스) | 3~5 |
| 3 | Vol. I~III (확정본을 얼굴 레퍼런스로) | 9~15 |
| 4 | 손·얼굴·발 부분 수정 | 3~6 |
| 5 | 배경 제거 | 소량 |
| (선택) | 바로크 장식 세트 1장 | 2~4 |
| | **합계 약 20~30 / 잔액 71.5** | |

전신이라 얼굴이 작아지므로 2k로 뽑아 세로 크롭에서도 얼굴 디테일을 지킨다.
진행은 `illust` 스킬 순서대로, 단계마다 결과를 보여주고 다음으로 간다.

## 7. 기술 방향

| 항목 | 내용 |
|---|---|
| 파일 | `index.html`(코드) + `img/*.webp` + 글꼴 조각. 코드만 바꾸면 그림은 다시 안 받음 |
| 그래픽 | 장식선·모래시계·글씨는 SVG 도형(필터 없이 — iOS에서 SVG 필터가 깨짐) |
| 흑백·채도 | 장식은 미리 흑백으로 만든 파일을 쓰고, 캐릭터 채도는 Vol.별로 처음 한 번 캔버스에서 처리. 매 프레임 필터 금지 |
| 레이아웃 | `POSTER[vol]` 표 하나에 Vol.별 띠·틀·조각·도형 배치 |
| 로직 분리 | 타이머·사이클·기록 계산을 화면과 분리해 브라우저 없이 테스트 |
| 재사용 코드 | 종이 구김(`drawPaper`), 시계탑 바늘, 초침 소리, 홈 화면 높이 보정(`appH`) |
| 저장 | `midnight.v2` 하나로. 옛 `midnight.rec` 기록은 처음 열 때 옮김 |

## 8. 성능 상한 (아이폰)

| 항목 | 상한 |
|---|---|
| 화보 완성 연출 | 60fps, 최악(조각 20개 + 별·새 + 종이 구김 동시)에서도 50 이상 |
| 집중 화면 | 모래만 움직임, 그리기 30fps 이하 |
| 뒤집힘 | 그리기 0 |
| 첫 화면 | 4G에서 2초 안 (첫 Vol. 그림만 먼저, ≤ 800KB) |
| 그림 전체 | ≤ 3MB (지금 4.8MB) |
| 한 화면 사진 조각 | ≤ 10개 |

## 9. 완료 기준 ★

**공부 흐름**
- [ ] 오늘 할 일 3개를 적고 앱을 껐다 켜도 남아 있다
- [ ] 할 일을 고르고 시작하면 25:00부터 1초씩 줄고 끝나는 시각이 표시된다
- [ ] 끝나면 회고 메모지가 뜨고 버튼 2번으로 닫힌다
- [ ] 회고 후 5분 휴식이 돌고 건너뛸 수 있다. 4번째 뒤에는 긴 휴식이 제안된다
- [ ] 집중 중 메모를 적으면 바로 집중 화면으로 돌아오고, 휴식 화면에 그 메모가 보인다
- [ ] 그만은 2초 길게 눌러야 동작한다

**딴짓 막기**
- [ ] 집중 중 폰을 뒤집으면 1초 안에 화면이 검게 되고, 들면 다시 켜지며 딴짓이 1 늘어난다
- [ ] 화면을 잠갔다 3분 뒤 켜면 남은 시간이 3분 줄어 있다

**화보**
- [ ] Vol. I~IV가 서로 다른 레이아웃·포즈로 보인다
- [ ] 집중 중에는 모래와 시간 숫자 외에 움직이는 것이 없다
- [ ] 집중을 끝내면 휴식 시작 때 다음 Vol.이 조각조각(스톱모션) 붙으며 완성된다
- [ ] 4번째를 끝내면 자정 표지 + 종 + 별 연출이 나오고 아카이브에 그날 화보집이 생긴다
- [ ] 캐릭터 외에는 색이 없고(흑백·은빛), Vol.이 올라갈수록 캐릭터 채도가 높아진다
- [ ] 세로에선 내민 손이, 가로에선 다리가 틀 밖으로 나와 보인다
- [ ] 시간 숫자가 어느 Vol.에서도 가려지지 않는다
- [ ] 새벽 4시 이후 처음 열면 새 밤(Vol. I)으로 시작한다

**기록**
- [ ] 아카이브에서 날짜별 화보집과 오늘·이번 주 통계(집중 시간, 할 일 달성률, 평균 집중도, 딴짓)가 맞게 나온다
- [ ] 옛 기록(`midnight.rec`)이 옮겨져 있다

**아이폰·품질**
- [ ] 홈 화면 앱 세로·가로에서 아래 빈칸이 없다
- [ ] 입력할 때 키보드가 입력칸을 가리지 않는다
- [ ] 비행기 모드에서도 열리고 글꼴이 깨지지 않는다
- [ ] 코드만 바꿔 배포하면 그림을 다시 받지 않는다
- [ ] 콘솔 오류 0건, 성능 상한 충족
