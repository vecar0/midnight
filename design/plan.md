# Minuit 2.0 기획서 (초안)

> 유지: **신데렐라 모티프 + 종이 콜라주.** 나머지는 전부 다시 정한다.
> 상태: 승인 전. 승인 전까지 코드·그림 생성 0.

---

## 0. 지금 버전 진단 (왜 다시 하나)

| # | 문제 | 근거 |
|---|---|---|
| 1 | **타이머와 장면이 따로 논다** | 처음엔 종이 팝업이 장면을 다 가리고, 장면을 펴면 타이머는 위쪽 작은 손잡이로 숨는다. 집중하는 동안 "진행되고 있다"는 느낌이 약하다 |
| 2 | **진행 피드백이 25분 동안 4번뿐** | 옷이 4번 바뀌는 것 말고는 화면이 거의 그대로. 모래시계는 작아서 잘 안 보인다 |
| 3 | **콜라주가 장식일 뿐 의미가 없다** | 오브젝트 20여 개가 처음부터 다 붙어 있다. 난잡하고, 집중과 아무 관계가 없다 |
| 4 | **그림체가 섞여 있다** | 캐릭터는 애니 일러스트, 오브젝트는 사진풍, 배경은 또 다른 풍. 이게 "AI 콜라주" 느낌의 큰 원인 |
| 5 | **끝난 뒤에 남는 게 없다** | 완주해도 숫자 기록뿐. 다시 올 이유가 약하다 |
| 6 | **무겁다** | 그림 51개를 base64로 넣은 4.8MB짜리 한 파일. 코드 한 줄만 고쳐도 홈 화면 앱이 4.8MB를 다시 받는다 |

## 1. 한 줄 컨셉

**"집중하는 동안, 재투성이 다락방이 한 조각씩 오려 붙여지며 자정의 무도회장이 된다."**

콜라주를 **진행 표시 자체**로 쓴다. 집중한 만큼 종이 조각이 화면에 붙고,
끝까지 채우면 한 장의 콜라주 그림이 완성돼 **스크랩북**에 남는다.

---

## 2. 핵심 흐름

```
[밤 준비]  과목·시간 고르기  ─→  [집중]  조각이 붙고 옷이 바뀜  ─→  [자정]  완성 장면 + 유리구두
                                        │
                                        ├─ 중간에 그만 → "자정 종" : 옷은 재투성이로, 붙인 조각은 남음
                                        └─ 끝나면 → (선택) 호박마차 휴식 5분 → 다음 밤
```

- **한 화면에서 다 한다.** 장면이 항상 전체 화면이고, 타이머·버튼도 콜라주의 종이 조각(라벨, 티켓, 초대장)으로 장면 안에 붙어 있다. 팝업↔장면 전환은 없앤다.
- 시작 전에는 버튼 조각들이 크게, 집중 중에는 작은 시간 라벨 하나만 남고 나머지는 접혀 들어간다.

## 3. 등장 요소 목록 (①)

### 3-1. 4막 (한 세션을 4등분)

| 막 | 이름 | 배경 레이어 | 캐릭터 옷 | 붙는 조각 예 |
|---|---|---|---|---|
| I | Cendres 재 | 다락방, 재, 빗자루 | 낡은 앞치마 | 깨진 찻잔, 재 묻은 편지 |
| II | Enchantement 마법 | 달밤 창문, 별가루 | 반쯤 변한 드레스 | 요술봉, 호박, 쥐 → 말 |
| III | Bal 무도회 | 샹들리에, 계단 | 무도회 드레스 | 초대장, 춤추는 실루엣, 악보 |
| IV | Minuit 자정 | 시계탑 12시 | 드레스 + 유리구두 | 시계 바늘, 유리 파편, 구두 |

- 막이 바뀔 때: 지금처럼 종이 가림막이 쓸고 지나가며 옷 + 배경 레이어가 바뀐다(이건 지금 버전의 좋은 부분이라 유지).
- **막 안에서도 계속 변한다:** 1막당 조각 3개 → 세션 전체 12조각. 25분이면 약 2분마다 하나가 날아와 붙는다.

### 3-2. 화면 요소

| 요소 | 역할 | 비고 |
|---|---|---|
| 캐릭터 | 주인공. 막마다 옷 변경 | 얼굴·머리 원본 유지(은발, 일자 앞머리, 처진 회색 눈+붉은 아이라인, 초커) |
| 배경 | 막마다 레이어 교체 | 4장 |
| 콜라주 조각 | 진행 표시 | 12개 + 스크랩북용 장식 |
| 시간 라벨 | 남은 시간 | 찢은 종이 라벨. 탭하면 컨트롤 펼침 |
| 모래시계 | 세션 진행률 | 지금처럼 캐릭터가 손에 든다. 모래 시뮬레이션 유지 |
| 시계탑 | **오늘 누적** 진행률 | 하루 목표 대비 바늘 위치(저녁 6시→자정). 실제 시각은 표시 안 함 |
| 유리구두 | 완주 보상 | 스크랩북 페이지에 찍힘 |

### 3-3. 기록 = 스크랩북

- 완주한 세션 = 완성 콜라주 1페이지(과목·날짜·시간이 손글씨 라벨로).
- 그만둔 세션 = 찢긴 페이지(붙인 조각만큼만 남음). 벌이 아니라 흔적.
- 위로 넘겨 보는 책 형태. 맨 앞에는 이번 주 요약(오늘 / 이번 주 / 연속일).

## 4. 시간·보상 규칙 (② 자원 대신)

| 항목 | 규칙 |
|---|---|
| 세션 길이 | 15 / 25 / 45 / 60분 + 직접 입력(5~120) |
| 조각 | 세션 길이 ÷ 12 마다 1개. 일시정지 중엔 안 붙음 |
| 하루 목표 | 기본 2시간, 설정 가능. 시계탑 바늘 = 오늘 누적 ÷ 목표 (6시→12시) |
| 유리구두 | 완주 1회당 1개 |
| 연속일 | 하루에 완주 1회 이상이면 +1. 놓치면 0부터 |
| 휴식 | 완주 후 "호박마차 5분" 버튼(선택). 휴식 타이머는 기록에 안 들어감 |
| 그만두기 | 2초 길게 눌러야 됨(실수 방지). 1분 이상 했으면 찢긴 페이지로 저장 |

## 5. 앱을 떠났을 때 (③ 적 AI 대신 — "방해" 규칙)

| 상황 | 동작 |
|---|---|
| 화면 잠금 / 다른 앱 | 타이머는 계속 감(끝나는 시각 기준 계산). 돌아오면 그동안 붙었어야 할 조각이 한꺼번에 날아와 붙음 |
| 엄격 모드(설정, 기본 끔) | 다른 앱으로 간 지 30초가 지나면 "자정 종" = 그만두기. 화면 잠금은 봐줌(구분이 안 되면 끔 유지) |
| 끝났는데 앱이 꺼져 있음 | iOS 홈 화면 앱은 서버 없이 알림을 못 보냄 → 다음에 열 때 완주 장면 재생. 기획상 한계로 명시 |

## 6. 조작 (④)

| 동작 | 결과 |
|---|---|
| 시간 라벨 탭 | 컨트롤 조각(시작/일시정지/그만/시간) 펼치기·접기 |
| "자정까지" 티켓 탭 | 시작 |
| 그만 길게 누르기 2초 | 그만두기 |
| 아래에서 위로 밀기 | 스크랩북 열기 |
| 기울이기 / 마우스 | 깊이감(지금 기능 유지, 더 약하게) |
| 과목 | 시작 전 초대장 조각에 입력. 최근 과목 3개 칩 |

키보드 바깥 높이 문제: 과목 입력은 화면 위쪽 1/3 안에 둔다(iOS 키보드에 안 가리게).

## 7. 화면 구성 (⑤)

```
세로                              가로
┌──────────────┐                 ┌────────────────────────────┐
│ [시계탑]  [25:00 라벨] │                 │[시계탑]          [25:00]   │
│                        │                 │                 캐릭터      │
│        캐릭터          │                 │ 조각  조각     (엎드림)     │
│      (모래시계)        │                 │                            │
│  조각          조각    │                 │ [초대장:과목] [자정까지▶]  │
│ [초대장: 과목]         │                 └────────────────────────────┘
│ [15][25][45][60]       │
│ [ 자정까지 ▶ ]         │
│ ── 위로 밀어 스크랩북 ─ │
└──────────────┘
```

- 시작 후: 초대장·시간 칩·시작 티켓은 종이가 구겨지며 화면 밖으로 → 시간 라벨만 남음.
- 완주: 화면 전체가 완성 콜라주로 멈추고 → 종이 액자로 줄어들며 스크랩북에 꽂히는 연출.

## 8. 그림 (에셋) 계획 — 크레딧 절약

**원칙: 그림체를 하나로 통일한다.** 캐릭터 레퍼런스 그림체(가는 선, 흑백 + 분홍 혈색)에 맞춰
배경·조각도 "손으로 그린 잉크 일러스트를 오려 붙인 종이" 느낌으로. 사진풍 오브젝트는 쓰지 않는다.

| 묶음 | 장수 | 생성 방법 |
|---|---|---|
| 캐릭터 세로 4옷 | 4 | 1장 확정 후 나머지는 편집(옷만 교체) |
| 캐릭터 가로 4옷 | 4 | 동일 |
| 배경 레이어 4막 | 4 | 세로로 뽑고 가로는 아웃페인트 |
| 콜라주 조각 12개 | 3장 | 한 장에 4개씩 모아 뽑고 잘라 씀 |
| 시계탑·바늘, 구두, UI 종이(라벨·티켓·초대장) | 2장 | 한 장에 모아서 |
| 종이 질감·찢긴 테두리 | 0 | 지금 것 재사용 |

합계 약 **17번 생성** + 수정 몇 번. 현재 잔액 71.5크레딧으로 모자랄 수 있어서
**1차는 세로만**(캐릭터 4 + 배경 4 + 조각 3 + UI 2 = 13), 가로는 2차로 미룬다.

## 9. 기술 방향

| 항목 | 지금 | 바꿀 것 |
|---|---|---|
| 파일 구조 | 4.8MB 한 파일 | `index.html`(코드만) + `img/*.webp` 따로. 서비스워커가 그림은 한 번만 받고, 코드만 갱신 |
| 빌드 | `tools/build.py` | 유지(합치기 대신 복사·버전만) |
| 로직/화면 분리 | 한 파일에 섞임 | `timer`(시간·조각·기록 계산)는 화면과 분리 → 브라우저 없이 테스트 |
| 그리기 | DOM + 캔버스 3개 | 장면은 캔버스 1개 + DOM UI. 종이 구김 효과는 지금 `drawPaper` 재사용 |
| 저장 | localStorage | 유지. 스크랩북은 페이지 데이터(조각 목록)만 저장, 그림은 다시 그림 |

## 10. 성능 상한 (아이폰 기준)

| 항목 | 상한 |
|---|---|
| 목표 프레임 | 60fps, 최악 장면에서도 50 이상 (iPhone 12급) |
| 최악 장면 정의 | 막 전환 가림막 + 조각 날아오기 + 모래 시뮬레이션 + 기울기 깊이감 동시 |
| 첫 화면 표시 | 4G에서 2초 안. 첫 화면에 필요한 그림만 먼저(≤ 800KB) |
| 그림 전체 용량 | ≤ 3MB (지금 4.8MB) |
| 동시에 움직이는 레이어 | ≤ 8 |
| 모래 알갱이 | ≤ 1,500 |
| 캔버스 해상도 | 기기 픽셀 2배까지만 |
| 집중 중 배터리 | 조각이 날아오는 순간 외에는 깊이감 30fps로 낮춤 |

## 11. 완료 기준 (⑥) ★

**타이머·기록**
- [ ] 25분을 고르고 시작하면 라벨이 25:00부터 1초씩 줄어든다
- [ ] 일시정지하면 시간이 멈추고, 이어서 누르면 멈춘 곳부터 간다
- [ ] 화면을 잠갔다 3분 뒤 켜면 남은 시간이 3분 줄어 있고, 그동안의 조각이 모두 붙어 있다
- [ ] 끝까지 가면 완주 장면이 나오고 스크랩북 맨 앞에 새 페이지가 생긴다
- [ ] 그만 버튼은 2초 길게 눌러야만 동작한다
- [ ] 1분 이상 하고 그만두면 찢긴 페이지가 저장되고, 1분 미만이면 아무것도 안 남는다
- [ ] 앱을 완전히 껐다 켜도 기록·과목·하루 목표가 남아 있다

**장면**
- [ ] 세션의 1/4, 2/4, 3/4 지점에서 가림막이 지나가며 옷과 배경이 바뀐다
- [ ] 세션 동안 조각이 정확히 12개 붙는다(일시정지 중엔 안 붙음)
- [ ] 모래시계 위쪽 모래가 남은 시간에 비례해 줄어든다
- [ ] 시계탑 바늘이 오늘 누적 ÷ 하루 목표만큼 6시→12시로 움직인다
- [ ] 중간에 그만두면 옷이 1막 옷으로 돌아가고 붙은 조각은 그대로다

**아이폰**
- [ ] 홈 화면 앱(세로·가로)에서 아래에 빈칸이 없다
- [ ] 과목 입력 시 키보드가 입력칸을 가리지 않고, 닫은 뒤 화면 높이가 원래대로 돌아온다
- [ ] 소리는 첫 터치 뒤에만 나고, 소리 끄기가 다시 켜도 유지된다
- [ ] 비행기 모드에서도 열린다(오프라인)
- [ ] 코드만 바꿔 배포하면 그림을 다시 받지 않는다(서비스워커)

**품질**
- [ ] 콘솔 오류 0건
- [ ] 위 성능 상한의 최악 장면에서 50fps 이상
- [ ] 모든 그림이 같은 그림체로 보인다(사진풍 오브젝트 없음)

## 12. 정해 주실 것

1. **조각이 붙는 콜라주 진행 방식**이 마음에 드는지 (이게 기획의 중심)
2. **시계탑 = 오늘 누적**으로 바꿔도 되는지 (지금은 실제 현재 시각)
3. 엄격 모드, 호박마차 휴식, 연속일 — 뺄 것이 있는지
4. 1차는 세로 화면만 하고 가로는 나중에 해도 되는지
