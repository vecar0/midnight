# Minuit 2.0 기획서 (초안 v2)

> 유지: **신데렐라 모티프 + 종이 콜라주.**
> 목표: 예쁜 타이머 → **실제로 공부가 더 되는 집중 도구.**
> 그림: **캐릭터만 새로 그린다.** 나머지 에셋은 전부 재활용한다.
> 상태: 승인 전. 승인 전까지 코드·그림 생성 0.

---

## 0. 지금 버전의 근본 문제

| # | 문제 | 공부에 미치는 영향 |
|---|---|---|
| 1 | 집중하는 **도중에** 화면이 제일 화려하다 (구름처럼 떠다니는 오브젝트, 깊이감, 반짝이, 옷 갈아입기) | 보상이 집중을 방해한다. 화면을 보게 만든다 |
| 2 | "무엇을 할지"를 안 정하고 시작한다 (과목 이름뿐) | 앉아서 뭘 할지 고민하다 시간이 간다 |
| 3 | 끝나고 돌아보는 단계가 없다 | 25분 동안 실제로 뭘 했는지 남지 않는다 |
| 4 | 휴식이 없다 | 연속으로 하다 지치거나, 쉬다가 폰으로 새어 나간다 |
| 5 | 폰을 손에 든 채 타이머를 켠다 | 타이머 앱이 곧 딴짓 도구가 된다 |
| 6 | 오브젝트(사진풍)와 캐릭터(일러스트)의 그림체가 따로 논다 | 완성도가 낮아 보인다 |

## 1. 한 줄 컨셉

**"하룻밤 = 집중 4번. 한 번 끝낼 때마다 마법이 한 단계 풀리고, 네 번째에 자정의 무도회."**

- 집중하는 동안에는 **조용하게.** 모래시계와 남은 시간만 보인다.
- 보상(옷 갈아입기, 콜라주 조각)은 집중이 **끝난 뒤 쉬는 시간에** 몰아서 보여준다.
- 공부 기법은 검증된 것만 쓴다: 시작 전 목표 정하기 → 25분 집중 → 짧은 회고 → 5분 휴식 → 4번째 뒤 긴 휴식(뽀모도로 사이클).

## 2. 핵심 흐름

```
[오늘의 초대장]  오늘 할 일 1~3개 적기 (하루 한 번)
      │
      ▼
[준비]  할 일 하나 고르고 "이번엔 어디까지" 한 줄 → 시간 고르기
      │
      ▼
[집중]  화면이 어두워지고 차분해짐. 폰을 뒤집어 두면 화면이 꺼진 채 진행
      │   └ 딴생각이 나면 "메모"에 던져 두고 바로 복귀
      ▼
[회고 15초]  다 했다 / 일부 / 못 했다  +  집중도 ★1~5
      │
      ▼
[호박마차 휴식 5분]  ← 여기서 보상 연출: 가림막 → 옷 한 단계 변신 + 콜라주 조각이 날아와 붙음
      │                휴식 제안: 물 마시기 · 스트레칭 · 눈 감기 (폰 보지 않기)
      ▼
   4번째면 [자정]  드레스 완성 + 시계탑 종 + 긴 휴식 15~30분 → 그날 밤 완성 페이지 저장
```

## 3. 등장 요소 (①)

### 3-1. 하룻밤의 4단계 (세션 하나 = 한 단계)

| 완료한 집중 | 단계 | 캐릭터 옷 | 장면에 붙는 조각 (기존 에셋) |
|---|---|---|---|
| 0번 (시작) | — | 1단계 옷 | 배경만, 거의 빈 무대 |
| 1번 | I Prélude 서곡 | 2단계 옷 | `oEnvelope`, `swirl`, `shard1~2` |
| 2번 | II Nocturne 야상곡 | 3단계 옷 | `watch1`, `watch2`, `crystals`, `shard3~5` |
| 3번 | III Valse 왈츠 | 4단계 옷 직전 연출 | `oWand`, `d3Feather`, `d3Gears`, `d3Pumpkin` |
| 4번 | IV Minuit 자정 | 4단계 드레스 | `d3Tiara`, `d3Slipper`, `d3Key`, `d3Shards`, `d3Watch` + 시계탑 종 |

- 지금은 오브젝트가 처음부터 다 붙어 있다 → **집중을 끝낼 때마다 하나씩 모이는 보상**으로 바꾼다.
- 중간에 그만두면 그 단계는 못 얻는다(이미 얻은 건 그대로). 벌은 이게 전부.
- 다음 날 새벽 4시에 새 밤이 시작된다(밤샘 공부가 날짜에 걸려도 끊기지 않게).

### 3-2. 화면 요소와 출처

| 요소 | 역할 | 에셋 |
|---|---|---|
| 캐릭터 4옷 | 단계 표시·보상 | **새로 그림 (유일한 생성 대상)** |
| 배경 | 무대 | `bgP`, `bgL` 재사용 |
| 시계탑 | 실제 현재 시각 (공부할 때 시간 확인용) | `tower2`, `hHour/hMin/hSec` 재사용 |
| 모래시계 | 이번 집중의 남은 시간 | 캐릭터가 손에 듦. 모래 시뮬레이션 코드 재사용 |
| 콜라주 조각 | 오늘 모은 보상 | 위 표의 기존 오브젝트 |
| 가림막 | 옷 바꿀 때 | `curtainP`, `curtainL` 재사용 |
| 종이 UI | 초대장·티켓·메모지 | `paperIvory`, `paperBlack`, `stripH/V` 재사용 |
| 반짝임 | 자정 연출 | `fx*` 재사용 |
| 안 쓰는 것 | 삭제 | `gKey` `gScrew` `gShard` `gShoe` `gWatch`, 가로 캐릭터 `l1~l4` |

### 3-3. 그림체 통일 — 크레딧 0으로

진짜 콜라주는 원래 사진과 그림을 섞는다. 어색한 건 섞여서가 아니라 **"오려 붙인 느낌"이 없어서**다.
그래서 모든 오브젝트에 코드로 같은 처리를 입힌다.

- 흰 테두리로 오린 자국(가위로 자른 듯한 불규칙한 외곽선) + 아래 그림자
- 흑백·대비 통일, 위에 종이 결 질감을 살짝 덮기
- 살짝 기울여 붙이기, 테이프 조각 한두 개

캐릭터도 같은 처리를 받아서, 캐릭터 역시 "오려 붙인 한 조각"이 된다.

## 4. 규칙 (② 자원 대신)

| 항목 | 규칙 |
|---|---|
| 집중 길이 | 25분 기본. 15 / 25 / 45 / 50분 선택 |
| 휴식 | 짧은 휴식 5분(45·50분이면 10분), 4번째 뒤 긴 휴식 15~30분. 건너뛰기 가능 |
| 오늘의 초대장 | 할 일 최대 3개. 세션마다 하나를 고른다. 다 하면 체크 |
| 세션 목표 | "어디까지" 한 줄(선택). 회고에서 이걸 다시 보여준다 |
| 회고 | 결과 3택 + 집중도 별 1~5. 15초 안에 끝나게 버튼만. 건너뛰면 기록만 남음 |
| 생각 메모 | 집중 중 떠오른 할 일·걱정을 한 줄로 던져 두는 곳. 휴식 때 다시 보여줌 |
| 그만두기 | 2초 길게 누르기. 5분 이상 했으면 "중단"으로 기록 |

## 5. 딴짓 막기 (③ 적 AI 대신)

| 장치 | 동작 | 아이폰 제약 |
|---|---|---|
| **폰 뒤집기** | 집중 중 폰을 화면이 아래로 가게 뒤집으면 화면이 검게 꺼지고(배터리 절약) 진행. 들어 올리면 "딴짓 1회"가 조용히 기록되고 화면이 켜짐 | 첫 터치 때 기울기 센서 허락 필요(지금도 받음). 화면 꺼짐 방지(Wake Lock)는 iOS 16.4+ |
| 차분 모드 | 집중 중엔 배경을 어둡게, 깊이감·반짝이·떠다니는 효과 끔. 모래와 시간만 | — |
| 화면 잠금 / 다른 앱 | 타이머는 계속 감. 돌아오면 남은 시간이 맞게 줄어 있음 | 서버 없이는 끝날 때 알림 못 보냄 → 끝나는 시각을 화면에 크게 표시("21:35에 끝나요") |
| 딴짓 통계 | 회고 화면에 "이번엔 2번 들었어요" | — |

## 6. 조작 (④)

| 동작 | 결과 |
|---|---|
| 초대장 탭 | 오늘 할 일 편집 |
| 할 일 칩 탭 → "자정까지" 티켓 탭 | 집중 시작 |
| 집중 중 화면 탭 | 시간·메모·일시정지 버튼을 3초간 보여줬다 숨김 |
| 메모 버튼 | 한 줄 입력 → 엔터 → 바로 닫힘 |
| 그만 2초 누르기 | 중단 |
| 아래에서 위로 밀기 | 기록 열기 |

과목·메모 입력칸은 화면 위쪽 1/3에 둔다(iOS 키보드에 가리지 않게).

## 7. 화면 구성 (⑤)

| 상태 | 보이는 것 |
|---|---|
| 준비 | 장면(배경 + 캐릭터 + 오늘 모은 조각) 위에 초대장·할 일 칩·시간·"자정까지" 티켓 |
| 집중 | 장면 어둡게, 캐릭터 + 모래시계 + 남은 시간 + 끝나는 시각. 나머지 숨김 |
| 뒤집힘 | 완전 검은 화면 |
| 회고 | 종이 메모지 한 장: 목표 한 줄 / 3택 버튼 / 별점 / 딴짓 횟수 |
| 휴식 | 보상 연출 → 휴식 타이머 + 휴식 제안 + 생각 메모 목록 |
| 자정 | 드레스 + 모든 조각 + 시계탑 종 + 반짝임 → "오늘 밤 완성" |
| 기록 | 오늘 / 이번 주: 집중 시간, 할 일 달성률, 평균 집중도, 딴짓 횟수 추세, 과목별 시간 |

**가로 화면:** 새 가로 캐릭터를 그리지 않는다. 세로 캐릭터를 오른쪽에 크게 두고
(무릎 위로 잘림), 왼쪽에 시계탑과 UI. 같은 그림을 쓰니 모래시계 좌표도 세로 것을 그대로 쓴다.

## 8. 그림 계획 — 캐릭터 4장만

| 순서 | 내용 | 모델 | 예상 크레딧 |
|---|---|---|---|
| 1 | 구도·그림체 시안 2장 (싸게) | GPT Image 2.5 Flare 저품질 (장당 0.25) | 0.5 |
| 2 | 1단계 옷 확정본 | Nano Banana Pro 1k (레퍼런스: 그림체 2장 + 지금 `p1`) | 2~4 |
| 3 | 2·3·4단계 옷 | 확정본을 레퍼런스로 넣고 **옷만** 바꾸는 편집 | 6~12 |
| 4 | 부분 수정 | 손·얼굴 등 문제 있는 곳만 | 3~6 |
| 5 | 업스케일·배경 제거 | 확정 4장 | 소량 |
| | **합계** | | **약 15~25 / 잔액 71.5** |

- 구도: 레퍼런스처럼 **무릎 위까지** 크게. 얼굴이 커져서 퀄리티가 살고, 드레스도 충분히 보인다.
- 포즈: 4장 모두 같은 포즈(모래시계를 두 손으로 가슴 앞에). 그래야 모래시계 좌표를 한 번만 재면 된다.
- 얼굴·머리 원본 유지(은발, 일자 앞머리, 처진 회색 눈+붉은 아이라인, 초커).
- 진행은 `illust` 스킬 순서대로. 단계마다 결과를 보여주고 다음으로 간다.

## 9. 기술 방향

| 항목 | 지금 | 바꿀 것 |
|---|---|---|
| 파일 | 4.8MB 한 파일 | `index.html`(코드) + `img/*.webp`. 코드만 고치면 그림은 다시 안 받음 |
| 로직 | 화면 코드와 섞임 | 타이머·사이클·기록 계산을 따로 떼서 브라우저 없이 테스트 |
| 재사용 | — | 종이 구김(`drawPaper`), 모래 시뮬레이션, 시계탑 바늘, 초침 소리, 홈 화면 높이 보정(`appH`)은 그대로 가져감 |
| 저장 | localStorage 3키 | `midnight.v2` 하나로(오늘 밤, 할 일, 세션 기록, 메모, 설정). 옛 기록은 처음 열 때 옮김 |

## 10. 성능 상한 (아이폰)

| 항목 | 상한 |
|---|---|
| 준비·보상 화면 | 60fps, 최악(가림막 + 조각 날아오기 + 모래 + 깊이감)에서도 50 이상 |
| 집중 화면 | 모래만 움직임. 그리기 30fps 이하, 1초에 한 번만 시간 갱신 |
| 뒤집힘 | 그리기 0 (검은 화면), 센서만 |
| 첫 화면 표시 | 4G에서 2초 안 (첫 화면 그림 ≤ 800KB) |
| 그림 전체 | ≤ 3MB (지금 4.8MB) |
| 모래 알갱이 | ≤ 1,500 |

## 11. 완료 기준 (⑥) ★

**공부 흐름**
- [ ] 오늘 할 일 3개를 적고 앱을 껐다 켜도 남아 있다
- [ ] 할 일을 고르고 시작하면 25:00부터 1초씩 줄고, 끝나는 시각이 표시된다
- [ ] 끝나면 회고 메모지가 뜨고, 버튼 2번(결과·별점)으로 닫힌다
- [ ] 회고 후 5분 휴식 타이머가 돌고, 건너뛸 수 있다
- [ ] 4번째 집중 뒤에는 긴 휴식이 제안된다
- [ ] 집중 중 메모 버튼으로 한 줄을 적으면 화면이 바로 집중 상태로 돌아오고, 휴식 화면에 그 메모가 보인다
- [ ] 그만 버튼은 2초 길게 눌러야 동작하고, 5분 이상 했으면 "중단"으로 기록된다

**딴짓 막기**
- [ ] 집중 중 폰을 뒤집으면 1초 안에 화면이 검게 되고, 들어 올리면 다시 켜지며 딴짓 횟수가 1 늘어난다
- [ ] 집중 중에는 깊이감·반짝이·떠다니는 효과가 꺼져 있다
- [ ] 화면을 잠갔다 3분 뒤 켜면 남은 시간이 3분 줄어 있다

**보상·장면**
- [ ] 집중 1번을 끝내면 휴식 시작 때 가림막이 지나가며 옷이 다음 단계로 바뀌고 표의 조각이 붙는다
- [ ] 집중 중간에 옷이나 조각이 바뀌지 않는다
- [ ] 4번째를 끝내면 자정 연출(드레스·종·반짝임)이 나온다
- [ ] 다음 날 새벽 4시 이후 처음 열면 새 밤(1단계 옷, 조각 없음)으로 시작한다
- [ ] 모든 오브젝트에 같은 오려 붙인 처리(테두리·그림자·종이 결)가 보인다

**기록**
- [ ] 기록 화면에 오늘·이번 주의 집중 시간, 할 일 달성률, 평균 집중도, 딴짓 횟수가 숫자로 맞게 나온다
- [ ] 옛 버전 기록(`midnight.rec`)이 새 기록으로 옮겨져 있다

**아이폰·품질**
- [ ] 홈 화면 앱 세로·가로에서 아래 빈칸이 없다
- [ ] 입력할 때 키보드가 입력칸을 가리지 않고, 닫은 뒤 높이가 원래대로 돌아온다
- [ ] 비행기 모드에서도 열린다
- [ ] 코드만 바꿔 배포하면 그림을 다시 받지 않는다
- [ ] 콘솔 오류 0건, 위 성능 상한 충족

## 12. 정해 주실 것

1. **보상을 쉬는 시간으로 옮기는 것**(집중 중엔 차분하게)이 괜찮은지 — 기획의 중심
2. **폰 뒤집기** 기능을 넣을지 (공부 효과는 가장 클 것 같지만, 폰을 책상에 세워 두고 쓰는 경우엔 못 씀 → 설정에서 끄기 가능)
3. 캐릭터 구도를 **무릎 위까지**로 바꿔도 되는지 (지금은 전신)
4. 가로 화면도 세로 캐릭터를 재사용하는 방식으로 괜찮은지
