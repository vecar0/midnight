## 1. 한 줄 컨셉

**"자정까지 집중 4번. 한 번 버틸 때마다 마법의 조각 하나 — 유리구두, 장갑, 헤드피스, 마지막 코트 — 를 입고, 4번째에 그날 밤의 화보 표지가 완성된다. 도중에 폰을 보면 마법이 하나 풀린다."**

- 세계는 흑백, **마법이 깃든 조각만 차가운 파랑(얼음·유리 빛)**. 조각을 모을수록 화면에 파랑이 늘어난다.
- 화면은 늘 패션 잡지 한 페이지: 큰 인물 컷 + 잡지 헤드라인 같은 큰 남은 시간.

## 2. 캐릭터

### 2-1. 인물

| 항목 | 내용 |
|---|---|
| 인상 | 20대 초반 모델 겸 대학생. 무표정에 가까운 차가운 얼굴, 카메라를 똑바로 봄 |
| 머리 | 흑발 장발(허리 아래까지 곧게), 눈썹을 덮는 일자 앞머리, 옆머리 몇 가닥이 얼굴선을 따라 내려옴 |
| 눈 | 반쯤 감은 나른한 눈매, 옅은 회색 눈, 눈가에 옅은 분홍빛 |
| 피부·화장 | 창백한 피부, 옅은 입술, 화장 최소 |
| 체형·포즈 | 마른 모델 체형. **5장 모두 같은 포즈**(서서 한 손은 주머니/허리, 한쪽 다리에 무게) — 갈아입을 때 같은 사람이 옷만 바뀌어 보이게 |

### 2-2. 옷 5단계 (조각 0~4개)

기본 옷은 레퍼런스(`design/ref/outfit_ref.jpg`)에서 퍼 코트만 빼고 그대로 가져온다. 마법 조각은 전부 **차가운 파랑의 유리·얼음·오간자** 질감 → 흑백 속에서 파랑이 하나씩 늘어난다.

| 단계 | 이름 | 새로 얻는 조각 (파랑) | 전체 옷 |
|---|---|---|---|
| 0 | **PRELUDE** 시작 | — | 검은 시스루 망사 긴소매 터틀넥, 속에 검은 뷔스티에, 에나멜 가죽 하이웨이스트 쇼츠, 녹아내린 듯한 은 버클의 넓은 가죽 코르셋 벨트, 검은 망사 스타킹, 검은 가죽 앵클부츠, 여러 겹 은 체인 + 십자가 펜던트 |
| 1 | **GLASS** 유리구두 | 투명한 푸른 유리 굽 플랫폼 힐(앵클부츠 대신) | 0단계 + 유리 힐 |
| 2 | **GLOVES** 장갑 | 팔꿈치까지 오는 반투명 푸른 망사·라텍스 오페라 장갑 | 1단계 + 장갑 |
| 3 | **CROWN** 헤드피스 | 티아라 대신 머리에 얹는 푸른 크리스털 헤어 체인 + 이어커프 | 2단계 + 헤드피스 |
| 4 | **MIDNIGHT** 완성 | 어깨에 걸친 길고 투명한 아이스블루 오간자 트렌치 코트(바닥까지 끌림) | 전부 + 코트 = 완성 룩 |

> 드레스 대신 **"자정의 코트"**로 마무리. 바꾸고 싶으면 승인 때 말씀해 주세요.

### 2-3. 그림 규격 (PixAI)

| 항목 | 규격 |
|---|---|
| 장수 | **5장**(단계 0~4). 세로·가로 모두 같은 그림을 잘라 씀 |
| 구도 | 정면, 머리끝부터 발끝까지 전신, 위아래 여백 조금 |
| 크기 | 세로 2:3, 긴 변 2048px 이상(세로 화면은 무릎 위까지 잘라도 얼굴이 선명하게) |
| 배경 | 밝은 회색 무지(배경 제거는 Claude가 처리) |
| 일관성 | 0단계를 먼저 확정 → 그 그림을 기준(이미지 참조/부분 수정)으로 조각만 더해 1~4단계 생성. 모델·시드·인물 설명은 5장 동일 |
| 진행 | 0단계 시안 몇 장 → 고르기 → 나머지. 단계마다 결과를 보고 다음으로 |

프롬프트 파일(`design/pixai_prompts.md`)은 **승인 후 v5 기준으로 새로 씀**(지금 파일은 v4용).

## 3. 흐름과 규칙

```
[준비] 과목 입력/선택 → 시작
  → [집중 25:00] 큰 인물 컷 + 큰 숫자. 화면 꺼짐 방지
       ├ 앱 나감/화면 잠금 10초 초과 → [실패] 마법 풀림 연출, 마지막 조각 하나 잃음 → 준비로
       └ 그만두기(2초 길게 누름) → 실패와 같음
  → [성공] 조각 획득
  → [휴식 5:00] 갈아입기 연출(조각 클로즈업 → 입은 모습) → 휴식 타이머
  → 4번째 성공이면 [자정] 종 12번 → 화보 표지 완성 → 저장 → 긴 휴식 제안
```

| 규칙 | 값 |
|---|---|
| 집중 길이 | 기본 25분. 설정에서 15~60분, 5분 단위 |
| 짧은 휴식 | 기본 5분. 3~15분 |
| 긴 휴식 | 4번째 뒤 기본 20분. 15~30분 |
| 세트 | 4번 고정 |
| 일시정지 | 없음 (엄격 규칙과 맞춤) |
| 이탈 유예 | 화면이 숨겨진 뒤 **10초**까지는 봐줌(알림 내리기·실수). 넘으면 실패 |
| 앱이 강제 종료됐을 때 | 다음에 열 때 집중 중이었던 기록이 있으면 실패 처리 |
| 실패 시 | 가장 최근 조각 1개 잃음. 조각 0개면 잃을 것 없음 |
| 휴식 중 이탈 | 자유 (휴식은 폰 봐도 됨) |
| 새 밤 | 새벽 4시에 조각이 0으로 초기화 |
| 화면 꺼짐 방지 | Wake Lock 사용. 안 되는 기기면 무음 영상 반복 방식으로 대체 |
| 시간 계산 | 시작 시각 기준으로 계산(타이머가 밀리지 않게) |

## 4. 화면 구성

### 4-1. 아트 디렉션

| 항목 | 내용 |
|---|---|
| 지면 | 흰 종이 `#F1F1EF` + 잉크 검정 `#0E0F12` + 회색 단계 |
| 파랑 | 아이스블루 `#9CC7E8` ~ 깊은 파랑 `#2D5D8A`. **마법 조각, 진행 점, 강조 1곳에만** |
| 입체감 | 레이어 3~4층(배경 사진 → 큰 글자 → 인물 → 앞에 떠 있는 유리 오브젝트 2~4개). 폰 기울기/마우스로 층마다 다르게 움직임 |
| 오브젝트 | 유리구두·크리스털·회중시계·유리 파편 등 2~4개만. 흑백 + 유리 부분만 파랑. 기존 `d3*`, `crystals`, `shard*`를 흑백 처리해 재활용 |
| 글꼴 | 헤드라인 Didone 계열 세리프(예: Bodoni Moda) · 숫자 같은 계열 큰 숫자 · 정보는 좁은 산세리프 대문자 · 한글은 Noto Sans KR. 필요한 글자만 잘라 오프라인 포함 |
| 잡지 요소 | 상단 매스트헤드 `MIDNIGHT`, 호수 `No. 027`(완성한 표지 수), 날짜, 옆 기사 제목처럼 단계 이름·과목 |

│ │ 컷  │ (헤드라인 크기)   │  머리가 숫자 일부를 살짝 덮음(지면 느낌)

### 4-4. 상태별

| 상태 | 화면 |
|---|---|
| 준비 | 지금 단계 인물 + 과목 입력칸(최근 과목 칩) + 시간 표시 + START |
| 집중 | 위 레이아웃. 움직이는 건 숫자·기울기 입체감·오브젝트 아주 살짝만 |
| 실패 | 잃은 조각이 유리처럼 깨져 흩어짐(파랑 파편) → "THE SPELL BROKE" + 한 줄 |
| 휴식 | 갈아입기: 새 조각 클로즈업(그림의 발·손·머리 부분을 확대) → 흰 섬광/종이 넘김 → 새 단계 전신 → 휴식 타이머 |
| 자정 | 종 12번 → 표지 레이아웃(매스트헤드·호수·날짜·"MIDNIGHT ISSUE"·오늘 집중 시간·과목 목록) → **이미지로 저장** 버튼 |
| 통계 | 오늘·이번 주 집중 시간, 7일 막대, 성공/실패 횟수, 과목별 합계 |
| 설정 | 집중·휴식 길이, 효과음/배경음 켜고 끄기 |

## 7. 기술

| 항목 | 내용 |
|---|---|
| 배포 | 지금처럼 GitHub Pages + 홈 화면 앱(manifest, sw.js 캐시 버전 올리기). 앱 이름 Minuit → **MIDNIGHT** |
| 파일 | `index.html`(코드) + `img/*.webp` 따로. 코드만 바뀌면 그림은 다시 안 받게 |
| 구조 | `src/core.js`(타이머·규칙·기록 — 화면과 분리, 브라우저 없이 테스트) + `src/ui.js`(화면) + `src/sound.js` |
| 입체감 | CSS transform만(필터·SVG 필터 금지 — iOS 사파리 문제) |
| 이탈 감지 | `visibilitychange` + `pagehide` + 몇 초마다 마지막 접속 시각 저장 |
| 저장 | `localStorage` 키 `midnight.v5` 하나 (설정·오늘 진행·세션 기록). 옛 기록(`midnight.rec` 등)은 옮기지 않음 |
| 표지 저장 | 캔버스로 표지 합성 → 공유 시트(사진에 저장) |

## 8. 성능 상한 (아이폰)

| 항목 | 상한 |
|---|---|
| 프레임 | 60fps. 최악 장면(실패 파편 60개 + 기울기 입체감 + 숫자 갱신)에서도 50 이상 |
| 집중 중 | 숫자 1초에 1번 갱신 + 입체감만. 큰 그림 다시 그리기 없음 |
| 레이어 | 움직이는 층 ≤ 6개 |
| 그림 전체 | ≤ 3MB (캐릭터 5장 × ~400KB + 배경 + 오브젝트) |
| 첫 화면 | 4G에서 2초 안 (현재 단계 그림 먼저) |

## 9. 완료 기준 ★

**타이머·규칙**
- [ ] START를 누르면 설정한 집중 시간(기본 25:00)부터 1초씩 줄고 끝나는 시각이 보인다
- [ ] 집중이 끝나면 조각 1개가 생기고 휴식(기본 5:00)이 시작된다
- [ ] 4번째 성공 뒤에는 긴 휴식(기본 20:00)이 제안된다
- [ ] 설정에서 집중·휴식 길이를 바꾸면 다음 판부터 적용되고 껐다 켜도 남아 있다
- [ ] 집중 중 홈으로 나갔다 8초 안에 돌아오면 그대로 이어진다
- [ ] 집중 중 홈으로 나가거나 화면을 잠그고 10초 넘게 있다 돌아오면 실패 화면이 뜨고 조각이 1개 줄어 있다
- [ ] 집중 중 앱을 완전히 끄고 다시 열면 실패 처리돼 있다
- [ ] 조각 0개에서 실패하면 0개 그대로다
- [ ] 그만두기는 2초 길게 눌러야 동작하고 실패와 같이 처리된다
- [ ] 휴식 중에는 앱을 나갔다 와도 실패가 아니다
- [ ] 집중 중 아무것도 안 만져도 화면이 꺼지지 않는다
- [ ] 새벽 4시가 지나 처음 열면 조각 0개, 새 밤으로 시작한다

**화보**
- [ ] 조각 개수(0~4)마다 해당 단계 캐릭터 그림이 보인다
- [ ] 휴식이 시작되면 새 조각 클로즈업 → 새 단계 전신으로 갈아입기 연출이 나온다
- [ ] 실패하면 잃은 조각이 깨지는 연출 뒤 한 단계 전 그림으로 돌아간다
- [ ] 4번째 성공하면 종 12번 → 표지 화면이 나오고, 저장 버튼으로 사진 앱에 저장된다
- [ ] 화면에서 파랑은 마법 조각·진행 점·강조에만 있고 나머지는 흑백이다
- [ ] 폰을 기울이면 배경·글자·인물·오브젝트가 서로 다르게 움직인다
- [ ] 남은 시간 숫자는 세로·가로 모든 단계에서 읽을 수 있다(인물에 가려 읽기 힘들지 않다)

**기록**

- [ ] 통계에 오늘·이번 주 집중 시간, 7일 막대, 성공/실패 횟수, 과목별 합계가 실제 기록과 맞게 나온다

**소리**

- [ ] 배경음·효과음을 각각 끌 수 있고 껐다 켜도 설정이 남는다

**아이폰·품질**
